## Summary

Activity 9 focused on applying security audit principles to a real-world case study: **Grace Community Fellowship (GCF)**, a church leveraging multiple technology platforms for ministry, donations, and communication.  
Key learning outcomes included:

- **Conducting a Security Audit** – Reviewed backups, content management, encryption, MFA, password policies, software updates, SSL, user access, vendor reviews, monitoring/logging, disaster planning, and data transparency.  
- **Categorizing Practices** – Classified GCF’s practices as:
  - *Good*: Backups, encryption, MFA, SSL certificates, vendor security reviews.  
  - *Adequate*: Content management, disaster response plans, monitoring/logging, user access reviews, data-use transparency.  
  - *Urgent*: Weak password policies, outdated systems with no patching, unnecessary/complex tools not aligned with GCF’s mission.  
- **Mission Alignment** – Explained how IT supports GCF’s mission of loving God, serving people, and making disciples through secure giving platforms, communication tools, and online worship streaming.  
- **Recommendations** – Summarized improvements including stronger password enforcement, retiring legacy systems, streamlining tools, centralizing monitoring, publishing a privacy notice, and formalizing disaster recovery drills.
